## 公共关注点分支

### 适用范围
- 适用于 `P001-P027`。
- 触发时机：系统已经根据前序答案拿到 `传递信息` 后，新增提问 `医生关注点问题`。
- `P028`、`P029` 仍按系统真实追问路径执行，不在本节做固定全排列。

### 公共问题
- `Q关注点` 医生关注点问题
  - 执行前，先读取当前 case 固化的 `focus_title`，作为本轮识别固定关注点的目标语义。
  - 系统会给出 `4` 个选项。
  - 其中有 `1` 个选项会与 Excel 当前行的 `临床医生可能的关注点（标题）/（内容）` 语义相近。
  - 该“语义相近选项”在 `4` 个选项中的位置不固定，测试时不能按 `A/B/C/D` 位置断言，只能按语义断言。
  - 执行时应将返回的 `4` 个选项与当前 case 的 `focus_title` 做语义比对，相似度最高的一项记为 `F1`。
  - 系统也可能允许用户输入自定义关注点。

### 分支规则

#### `F1` 语义相近选项分支
- 条件：先取当前 case 的固定 `focus_title`，再从接口返回的 `4` 个选项中识别出与其语义最接近的一项；用户选择该项。
- 预期：
  - `focus_point.items[].title` 使用 Excel 当前行的 `临床医生可能的关注点（标题）`。
  - `focus_point.items[].content` 使用 Excel 当前行的 `临床医生可能的关注点（内容）`。
  - `focus_point.literatures` 优先使用 Excel 当前行的 `参考文献` 与 `研究简介及结果` 对应的信息。
- 判定口径：
  - 只要系统命中的关注点语义与 Excel 当前行一致，即视为走 `F1`。
  - 不要求该关注点出现在固定选项序号。
  - 若有多个选项都较接近，则取与 `focus_title` 相似度最高者作为 `F1`。

#### `F2` 其他选项 / 自定义关注点分支
- 条件：
  - 用户选择了其他 `3` 个非表格固定语义的关注点之一；或
  - 用户自行输入了明确、有效的关注点文本。
- 执行形态：
  - `F2-选项模式`：若本轮识别出的 `F1` 为某个固定选项，则从剩余非 `F1` 的 `3` 个选项中任选 `1` 个作答。
  - `F2-自定义模式`：若本轮走手动输入关注点，则暂定从以下关注点池中随机选择 `1` 个输入：
    - `医保政策`
    - `不良反应`
    - `采购优惠`
- 预期：
  - 拜访计划中的 `focus_point` 按用户实际关注点由 AI 动态生成。
  - 此时不再强制要求 `focus_point.items[].title/content` 命中 Excel 当前行的固定关注点标题与内容。
  - 但前面已经确定的 `医生类型`、`医生梯度`、`传递信息` 仍应保持不变。
  - `F2-选项模式` 下，断言重点是“系统未回落到 Excel 固定关注点”。
  - `F2-自定义模式` 下，断言重点是“系统围绕实际输入的关注点生成内容”，而不是回落到 Excel 固定关注点。

#### `F3` 无效输入回退分支
- 条件：用户对 `Q关注点` 输入无效值，例如：
  - `""`
  - `不知道`
  - `不清楚`
- 预期：
  - 系统回退并使用 Excel 当前行的固定关注点信息。
  - 即 `focus_point.items[].title/content` 以及相关参考信息，按 Excel 当前行的 `临床医生可能的关注点` 信息生成。
- 判定口径：
  - `F3` 的最终关注点结果应与 `F1` 命中的固定关注点结果一致。
  - 为便于执行，推荐优先统一使用 `不知道` 作为 `F3` 的标准输入值。

## 执行建议
- 每条主路径执行 `1` 次即可。
- 若只验证主干可达性，可对每条主路径只执行 `1` 次。
- `P001-P027` 在执行时，都需要继续进入一次 `Q关注点`。
- 本轮关注点分支建议直接按上文“推荐执行分配”执行，不再临时随机决定。
- `Q关注点` 的执行顺序建议为：
  - 先读取当前 case 固化的 `focus_title`。
  - 再从接口返回的 `4` 个选项中，识别与 `focus_title` 语义最接近的一项，记为 `F1`。
  - 对于分配到 `F2-选项模式` 的 case，从剩余非 `F1` 选项中任选其一。
  - 对于分配到 `F2-自定义模式` 的 case，从 `医保政策 / 不良反应 / 采购优惠` 中随机选择 `1` 个作为输入关注点。
  - 对于分配到 `F3` 的 case，输入无效值，推荐统一使用 `不知道`。
- 覆盖策略采用“固定分配 + 全局覆盖”：
  - `P001-P027` 不做单路径全排列。
  - 通过上文已指定的 `F1 / F2 / F3` case 分配，保证本轮执行必然覆盖到三类分支。
  - 其中 `F2` 需要额外覆盖两种子模式：`F2-选项模式` 与 `F2-自定义模式`。
- `F1` 与 `F3` 需要断言 Excel 当前行的固定关注点信息。
- `F2-选项模式` 需要断言关注点内容未回落到 Excel 固定关注点。
- `F2-自定义模式` 需要断言关注点内容由用户输入的 `医保政策 / 不良反应 / 采购优惠` 驱动生成，而不是强行回落到 Excel 固定关注点。
- `P028`、`P029` 不再做人造全排列，只验证是否能沿真实 AI 追问拿到最终拜访计划。
